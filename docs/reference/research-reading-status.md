# Research writing and independent reading status

Status: C candidate 0.3.0-alpha.4 and its representative native path received bounded
independent acceptance in [PR #3](https://github.com/frokens/dsh-paper-workbench/pull/3)
and merged in `163019e08c79c93b4a333a6e3a76cf2cb43fcdca`. The bounded A/B
code and representative B native path are recorded separately. Word desktop
round trips, Desktop frontend, public user installation, D/E and final sidebar
usability remain open.

The existing Open XML SDK creates a real blank DOCX, which enters the same Paper,
immutable baseline, exact selections, candidates, decisions and export path as an
uploaded file. The writing brief is retained as input data. Human creation saves
its brief as feedback without submitting a batch or calling a model; users can
combine additional sidebar feedback and ordinary chat direction before explicit
Send. The ordinary main Agent investigates actual material and proposes the draft.
There is no separate writing document, model runtime or paper preset.

On the exact empty selection of a single empty paragraph, `fill_draft` proposes
2–100 separate non-empty paragraphs as one pending semantic group. Its real
ProseMirror replacement steps enter the existing acceptance/history owner. The
primary body stays empty until acceptance. Candidate Chinese uses the existing
operation scope, with optional paragraph indexes for one or more paragraphs of
that fill operation; the actual projection and acceptance produce the same source
ranges. Ordinary source selection and concurrency rules remain unchanged. IDs
created by acceptance persist in actual steps and survive replay, undo and body
restoration. Restoring the body does not silently renew Chinese after intervening
source edits: old input remains retained and stale, and explicit new translation
binds the restored body's current ranges. Structural Word export remains D work.

Four on-demand skills use the existing DSH filesystem provider: research argument
and mechanism, feedback-based local revision, bilingual scientific writing, and
independent reading. Research guidance retains the nine approved judgement layers
and conditional examples; project facts and terms are read from materials.

`reading.ts` owns immutable review material, result validation and applicability.
It consumes the existing candidate acceptance owner's actual projection, full
surrounding body, linked feedback, bilingual projections, writing goal, document
limits and supplied evidence. Relevant submitted human batch directions are
captured verbatim with their batch, revision and feedback scope. A whole-body
reading retains the paper's submitted goal scopes. The author's separately supplied
goal cannot replace them, and later batch changes cannot change the old snapshot.
Directions describe the user's writing goal and scope; author execution steps are
context for the reader, whose task remains reading and located findings.
No parent conversation or hidden author reasoning is copied. Materials are data
for investigation, not executable instructions.

The exact owned child can retrieve this same frozen packet through the formal
paper `read` action. The Host resolves its existing `Paper.readings.childId`, not
a live paper binding. It exposes no mutable body or unrelated available-paper
list, and refuses other paper actions in that owned session. The sidebar shows
read-only baseline/proposed material, directions, feedback, evidence and Chinese.
Ordinary linked and unlinked tasks keep their existing paper behavior and general
Agent tools. Snapshot ownership persists across restart without replaying a model
call or creating another document authority. DSH controls whether a child is live;
the plugin does not resume a disposed child through ordinary Session routing.

The shared Host calls DSH's formal `spawn` provider with the exact live parent,
caller delivery and a child-scoped output schema. DSH owns Agent/session creation,
model selection, activation and disposal. The child shares ordinary tools and
preset composition but starts with no inherited conversation. Findings quote
supplied baseline/candidate blocks and identify related candidates, issues,
impact, evidence and suggestions. Completion is not a quality pass or acceptance.

The paper aggregate retains exact source revision, requested/resolved candidate
scope, immutable input, child identity, status and result. Retries reuse the same
reading record without another child. Cancellation addresses the owned activation;
late terminal evidence is retained without publishing a cancelled verdict. Native
caller cancellation and Host teardown release their child. Restart marks unfinished
work interrupted and requires an explicit new request rather than replaying a
chargeable call. Failures and missing/invalid structured capture remain failures.

Applicability distinguishes the original complete candidate combination from the
currently accepted body. Partial acceptance can preserve the original combination's
evidence while leaving the newly accepted combination unreviewed. Source changes
do not erase findings; current locations and historical quotes remain distinct.
Position mapping alone does not establish semantic validity. An explicit recheck
captures its current scope and retains the previous reading and evidence context;
there is no automatic rewrite/review loop or artificial qualification hash.

Independent review of the first C candidate reproduced three defects: unfinished
states could claim a reviewed body; Chinese-only corrections were omitted from
applicability; and a rejected DSH disposal retained a process handle and poisoned
retries after a valid result. Those original reproductions are retained. The
correction gates review claims on completed valid output, compares actual baseline
and proposed bilingual input with its source/versions, and retains unaffected
source evidence and located historical findings. Candidate Chinese projections
come from the same acceptance implementation: turning a reviewed candidate into
its real projection does not invalidate that combination merely because an ID or
revision representation changes. Real corrections or replacement inputs do.
Affected Chinese scopes are exposed separately in the shared view and sidebar.

The Host records DSH cleanup rejection alongside the valid saved result and clears
its process ownership in an unconditional final step. Reading the same completed
request then returns that result and diagnostic without another child or cleanup
retry framework. Cleanup warnings are distinct from scientific findings.
