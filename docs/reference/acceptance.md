# 验收标准

状态：实施前约定的必选验证及声明边界，尚无产品通过记录。PR 按实际职责选择受影响
项，最终收口必须覆盖完整产品路径。失败保留准确输入、命令、版本、结果和有用证据。

## 1. 验证与结论分层

| 层次 | 能证明什么 | 不能替代什么 |
| --- | --- | --- |
| 静态/类型/合同 | 代码与 schema、工具说明、依赖和接口一致 | 真实宿主加载和用户体验 |
| 单元/聚焦集成 | 操作、状态、映射和具体失败传播 | 真 DSH、真实模型和文档客户端 |
| 真实 DSH 工程验证 | 安装、服务、工具、Client、事件和重启链路 | 写作质量和导师接受意见 |
| 原生 Agent 使用 | Agent 理解工具并按反馈调查和提交候选 | 文献/实验真实性与完整业务正确 |
| Word 文件闭环 | 实际输入/导出 DOCX 的文本、批注锚点、差异、原件与属性 | Microsoft Word 实机操作和任意版式无损 |
| 文档客户端往返（扩展） | 实际客户端可审阅修订、定位批注与返稿 | 写作质量和所有格式无损 |
| 主控产品接收 | 按任务独立检查功能、设计、支持域及证据 | 未检查平台与未执行能力 |

## 2. 核心修订场景

| 场景 | 期望行为与必要验证 |
| --- | --- |
| 原生主对话文档输入 | 附件、@文件/路径、下载后的链接文件和从头写作进入同一后台；Agent 传文件引用而非 base64，侧栏自动展开；导师返稿也沿此入口，基准不猜测 |
| Word 式批注 | 正文/译文准确选区高亮、批注同屏、自动保存、回复及解决/重开；一次提交整轮，保存不调用模型，失败以原请求身份恢复 |
| 系统自动独立审读 | 正式轮次边界聚合完整候选及成对译文，首稿/主聊天修改均覆盖；同组合幂等、普通问答不触发、读者不递归；无手动启动/配置表单或自动接受 |
| 一句反馈、同段其他内容应保留 | 精确片段被替换，未授权内容保持；差异能从真实结构复算 |
| 同文多次出现相同句子 | 使用准确选区定位；歧义不猜测，不能错贴 |
| 重启与恢复 | 正文、待处理反馈、建议和用户决定可读；不靠聊天摘要重建 |
| 正文更新、旧译文返回 | 源修订不符则不覆盖新译文；UI 不把旧译文当当前内容 |
| 中文译文纠正 | 英文不被自动改写；意图与状态可解释 |
| 中文表达内容调整 | 对应英文与中文形成准确关联的候选，接受后含义一致 |
| 用户在生成期间编辑 | 未受影响选区可重定位；重叠/失效范围提示冲突 |
| 段落拆分/合并/移动 | 反馈、译文和来源关系有正确后继，无法确认时显示待核对 |
| 部分接受与跨位置依赖 | 依赖组不产生无效半组；实际组合的审读适用性被核对 |
| 接受/拒绝/撤销/全部接受 | 当前正文和历史正确；重复请求无重复插入；范围不静默改变 |
| 保存失败、取消和迟到结果 | 无半接收正文、不误报成功；请求资源退出，已保存反馈保留 |
| 外部文件变化 | 作为候选/导入变化呈现，不无提示覆盖已接受正文 |

每项主要在职责 owner 层验证，跨层选必要代表性贯通，不给每个字段重复启动真实链路。

## 3. 双语和写作验证

用合成研究材料或已授权材料提供准确事实、术语、文献与明确反馈，包含至少以下差异：
主体/执行职责、条件/否定、数字、结论强度、段落因果承接、引用与证据缺口。

判定反馈真实意图是否得到回应，允许不同合理措辞与方法；不能只与参考答案字符串匹配。
评价无关改写时排除明确必要的联动修改，并把修改质量与改动量分别判断。

从头写作需要真实材料依据；缺结果时不得补数。过程残留与研究对象术语按语境审读；
研究边界、有效条件和证据限制保留。技能改善效果没有实验前不宣称已证明。

## 4. 独立审读验证

从实际 DSH 轨迹核新的空对话会话、准确材料、候选修订、子会话作用域、输出、取消与
资源退出。不能只有封装函数被调用或父会话自评文本。

审读发现定位到实际问题；未完成/失败准确呈现。受影响候选更新后的结论绑定正确。
报告同模型上下文隔离的局限，用户接收与审读建议分开。避免无限自改循环及预算扩大。

## 5. DOCX 文件闭环与扩展往返

使用合成、可再分发 DOCX 夹具覆盖支持的正文、强调/链接、标题、列表、图表/题注、
引用、公式/脚注、批注和既有修订。复杂对象分支持/保留/待核对，禁止静默损失。

按用户收敛后的范围，一个代表性 Word 文件闭环必须完成：

1. 在真实 DSH 主对话上传带批注的 DOCX 或提供其文件路径，沿普通 Agent 和同一后台
   导入；保存输入原件，记录真实文件及必要入口轨迹。文件内容不被当作执行指令。
2. 提交有准确范围和理由的修改建议，由用户确认所需改动；保留无关文本和原批注。
3. 通过已有导出操作生成并下载真实 DOCX。下载稿保留/定位原批注，实际修改有可见
   的新批注或修改说明；继续复用原生修订，不另造后台或用文字报告冒充文件。
4. 对实际原稿/下载稿再解析，核正文真实差异、批注文本、锚点/原始引用及变化说明；
   核输入原件字节保全、导出可选作者/生成器等属性。锚点迁移、只读对象和范围限制如实报告。
5. 交付可再分发的真实输入、下载文件及简短对照说明，能对应每处实际文本和批注变化。
   SDK/XML 文件核验与原生主对话入口证据分开，不把离线文件夹具称为全链路通过。

桌面 Microsoft Word 自动化、Word 中真实接受/拒绝、SaveAs PDF、命名样式与真实版面，
以及复杂导师返稿的三方合并/严格客户端往返均为扩展能力。已有干净/修订/双语 DOCX、
PDF 和返稿后台继续复用，按各自实际范围报告；不承诺任意版式无损，不因这些扩展
过去未验阻塞最小 Word 文件闭环。已有六件真实 Word 结果、未保存返稿与原失败按原范围
保留，不重复运行 Word 或调整 AppleScript 来满足新目标。

若另行验证扩展客户端能力，记录实际客户端/版本及保存输出；XML、LibreOffice 或
预览 PDF 仍不能冒称 Microsoft Word 实机。本次范围变化不把旧未验项改为通过。

## 5.1 插件 PDF 交付（独立出口）

插件自身的 PDF 导出仍按原范围验收：通过既有导出 owner 取得真实 PDF，核代表页的
文本、双语字体、公式/表图及分页，说明干净/对照用途；检查实际文件属性与必要注释。
已有未改且适用的配置字体路径、渲染页、取消和重启证据直接复用，默认字体发现问题
继续如实保留。用户缩小的是 Word 客户端要求，不是删除插件 PDF 能力；Word 内
SaveAs PDF 属扩展，插件 PDF 也不作为本次最小 DOCX 样例的新前置。

## 6. 真实 DSH 与通用能力

通过实际待发包在正式 DSH 测试 profile 安装，记录发行版、OS/架构、配置差量及入口。
观察工具与 Skills 的可见性和真实调用、工作台加载和交互，完成上传修订与从头写作。

入口必验：已有普通任务、新建任务、重启恢复任务及非论文任务均能直接打开同一插件
侧栏；无论文时空态可用且不自动注入论文上下文。操作不创建/替换主 Agent，不要求
切换角色、preset、profile 或论文专用会话。原生对话 UI、消息、工具呈现和主输入框
保持原样；反馈和修订控件位于插件侧栏。不同任务视图隔离，同一论文显式关联时不
复制权威正文。独立“论文 Agent”创建页不能满足该验收。

验证普通聊天、项目/文件调查、代码编辑、命令执行、已有检索/MCP 的未受影响路径。
只检查已配置且获授权的能力，不为验收擅自连接外部账号、开启新服务器或扩大权限。

Client 主题、可访问标签、选区定位、窄屏/展开、键盘和错误恢复在实际宿主检查。
静态 HTML 或单独浏览器页面不满足该项。

## 7. 使用者安装和发布

- 从公开已构建 Release 取得候选包；无开发者源码、绝对路径、私人 registry 或编译要求。
- 独立审查者按安装指南复现，记录实际包与环境，不只读说明。
- 包含必要 Host/Client、资源、Skills、许可和依赖，缺失组件提供准确可行动原因。
- 重启恢复；升级保留数据；卸载清理插件资源并保留论文；不污染用户正常 profile。
- OS/架构/DSH 版本矩阵真实填写，未验项明确标出。兼容范围来自证据而非编译推断。
- 实际包文件列表、可选作者/生成器等属性和隐私内容经过检查；第三方许可保留。
- 核发布文件确实是经过验证的候选产物；不得用工作树干净、无关源码摘要变化要求
  全项目重复验证或让资源失去资格。

## 8. 课程评估规划

评估普通 DSH、相同写作 Skills 的 DSH、完整插件，并按独有问题消融独立审读/中文
视图。模型、资料和预算尽量可比，额外调用成本单独记。交互比较优先使用相同候选，
避免生成差异混入界面结论；等价任务与顺序平衡减少熟悉效应。

指标：反馈意图落实、无关改写、双语语义、人工定位/核对时间、漏看/误接收、导师改动
保留、审读新增发现与误报、延迟与调用成本。先试点再决定规模，不编造样本量、效果
或显著性。公共数据可评估 ARIES 等的许可及适用性，不能把研究数据中的指令照抄执行。

## 9. 接收报告

每个 PR 给出功能判断和架构判断，说明实际变更、读取范围、运行证据、失败、复用部分、
未覆盖事项和下一动作。主控按六向规则审查，最终接收必须明确真实 DSH、Word 文件闭环、公开
安装及支持矩阵的范围。缺必验证据时可以接收有界代码批次，不能标完整产品完成。
